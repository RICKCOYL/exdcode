UX / UI DESIGN · GROUP PROJECT

AcadeMedia

Making workplace learning easier to explore, navigate and continue.

ProjectEmployee learning platform
RoleUX/UI designer · Equal collaboration
FocusDashboard · Course discovery · Filtering

Overview

AcadeMedia is a learning platform concept that brings employee training, course discovery and learning progress into one experience. The interface includes a personal dashboard and a course catalogue where employees can browse training opportunities and narrow down results.

This was a collaborative project developed with a fellow designer. We shared responsibility for the design work and contributed equally to the outcome.

The Challenge

Employees need to find relevant training without getting lost in a large catalogue. They also need a clear way to return to ongoing courses and see upcoming tasks.

The design challenge was to make both discovery and continued learning feel straightforward.

Design Process

We worked collaboratively on the platform's interface, exploring how information could be organized across the dashboard and catalogue. The screens show a consistent visual language, course cards, search and filtering controls, and clear entry points for continuing training.

The aim was to balance a useful overview with enough detail to help employees choose their next step.
